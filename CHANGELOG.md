# Изменения

## 1.0.8 — 26.09.2026

По отчёту нового тестировщика без памяти (оценка 7/10).

**Ошибки**
- «Исправить время» на делах из чата и демо: поле ввода без секунд, поэтому то же время считалось изменением. Подписанный акт не давал исправить даже окончание, простое «Сохранить» делало заявление устаревшим и стирало отметку «Подано». Теперь время до минуты — не изменение.
- «Отключили по плану» не прятало кнопку «Записать» (стиль кнопок перебивал `hidden`).
- Номер заявки получен позже начала, акта нет — предупреждение: время до звонка подтвердит только акт (и в приложении, и в боте).
- Карточка дома: при ошибке в одном поле — «⚠️ Не сохранено», а не «сохраняются сами»; в заявлении так же.
- «Заявление устарело» — с кнопкой «Скачать новое»; после «Добавить квартиру» её заявление раскрыто.
- Мелочи: огромная сумма — «проверьте сумму», а не «не число», и «Положено» не показывает миллионы; «0» в полученном перерасчёте подсказывает настоящие кнопки; пустое время начала — ошибка, «ничего не поменяли» — «Время не изменилось»; «Дело не найдено» с кнопкой «На главную».

**Удобство и тексты**
- Главная: демо 1 перед демо 2; «вернули меньше положенного» — среди активных дел.
- «Деньги» для «Холодно» и «еле тёплая» — по замерам, без «с каждым часом больше»; без повтора про +40 °C; при нуле — одна строка.
- Мусор: «номер обращения», «когда позвонили оператору». «Стало тепло» вместо «починили» в подсказке.
- Акт — обычным текстом; «Записать проблему»; короткий ответ на повторное сообщение; «Это УК или поставщик?»; «уже здесь: 2 жителя»; свет — «2 часа в месяц» везде одинаково; подсказка демо 1 после «Подано».

## 1.0.5 — 24.09.2026

По отчёту «жюри + новичок» и замечаниям команды.

**Два демо — два способа доказать нарушение**
- «🧪 Демо» спрашивает, какой случай показать: **1 — дозвонились**, есть номер заявки; **2 — не дозвонились**, номера нет, доказательство — акт с соседями. Во втором два демо-соседа сами вписываются в акт (сообщений им бот не шлёт), дальше «Акт подписан» → «К делу» → «Воду дали» → заявление с актом.
- Демо мини-приложения (`npm run seed:demo`, `npm run demo`): демо 1 — заявление готово, получатель уже подставлен; демо 2 — акт собран, осталось отметить подпись; архив — дело, по которому вернули деньги. Демо в разных месяцах и по разным услугам: расчёты не складываются. Вверху демо-дела — подсказка, что нажать.

**Заявление подробнее по п. 105–106 Правил**
- Абзац о фиксации: куда сообщили (п. 105), номер, время регистрации и кто принял сообщение (п. 106), с этого времени считается нарушение (п. 111). Для соседа — что сообщил другой житель дома.
- Не дозвонились — «Дозвониться не удалось, хотя аварийная служба обязана ответить не позднее 5 минут (п. 13 Правил № 416)»; время начала — из акта.
- Необязательное поле «Кто принял заявку» в мини-приложении; бот при звонке напоминает записать, кто принял.
- Подписали акт после скачивания заявления — заявление помечается устаревшим (в нём нет акта).
- ФИО и квартира для заявления берутся из акта, если житель в нём есть, — заново не спрашиваем.

**Мини-приложение**
- Время начала не подставляется «сейчас» молча: кнопки «Только что», «1 ч назад», «3 ч назад», «Вчера в это же время» или ввод вручную; начало больше месяца назад — переспрашиваем.
- Нет ни номера заявки, ни подписанного акта — предупреждение «Пока нет доказательства» и что делать.
- Квитанции за этот месяц ещё нет — подсказка взять сумму из прошлой.
- Статус после подачи: «Подано — ждём квитанцию за …»; до подачи — «Заявление готово — осталось подать».
- Проще слова: «поставщик» вместо «ресурсоснабжающая организация», без «шапки» и «исполнителя»; кто такой председатель совета дома.
- Город не из справочника и новый дом — не ошибка: спокойное пояснение вместо предупреждения.
- Дату подачи нельзя поставить завтрашним днём (и на сервере).
- Вне MAX (в обычном браузере) вызовы моста MAX больше не сыплют ошибками в консоль.

**Акт без председателя**
- Бот заранее говорит, что без председателя совета дома акт подписывают одни жители: в сообщении «Акт готов к подписи» и на экране акта.

**Документация**
- README: сначала — что это и зачем, потом быстрый старт; оба демо; убраны противоречия (число тестов, версия Node, нумерация шагов) и устаревшее «Bot API не проверялся».

## 1.0.4 — 24.09.2026

Исправления по третьему строгому отчёту (82 сценария, оценка 5/10).

**Документы**
- Требование о штрафе и жалобы датируются днём, когда их готовят, а не датой заявления; в приложениях «отражён не полностью», если вернули часть; заголовок жалобы — по виду нарушения; адресат жалобы — жилинспекция из карточки дома; у требования — отметка о принятии.
- Заявление устарело (исправили время, добавили отключение за тот же месяц, сменился ответ про лифт) — экран предупреждает, новое скачивание даёт новую дату, старая отметка о подаче сбрасывается.
- Официальный язык в расчёте вместо разговорного; «Итого» при нескольких месяцах; «−5 °C» вместо «+-5»; «736 × 0,15% = 110,4%, но не больше 100%»; длинный перерыв упоминается один раз; отметка о принятии не разрывается между страницами; «кому» и «от кого» разделены.
- Повторный звонок: в заявлении оба номера заявки. Акт в демо помечен «демонстрационные данные».

**Расчёт и данные**
- Ответ «есть лифт» — один на весь дом (карточка дома); сменился — дела света пересчитываются, закрытое «без денег» может открыться для заявления.
- Летом (июнь–август) отопление не считается; замеры до начала дела не учитываются, а сдвинуть начало позже замера нельзя.
- «Нет горячей воды» и «еле тёплая» (и отопление) не оплачиваются дважды за одни часы — и для закрытых дел тоже.
- Копейки одинаковые на экране и в документе (округление вниз); «1.250,50» понимается; нереальные суммы, 0, температуры вне разумных пределов, ИНН с ошибкой в контрольной цифре, «Я» вместо ФИО — ошибки у полей.
- Квартира и лицевой счёт — данные адреса: «не запоминать» стирает только ФИО; квартира из адреса попадает в заявление нового жителя.
- Дата подачи не раньше даты заявления; входящий номер без «№ №»; «перерасчёт сделали / не сделали» — только когда пришла квитанция.
- Адрес «тверская д1» — тот же дом; латиница и незнакомые города — с предупреждением.

**Новое**
- Вторая (третья…) квартира в том же доме: в деле блок «Ещё квартира в этом доме?» — по каждой квартире своё заявление со своим лицевым счётом и платой.
- Часы, когда горячая вода была ниже +40 °C, — в рублях: по объёму горячей воды за месяц и двум тарифам из квитанции (оценка при равномерном расходе); сумма попадает в заявление и в документы, если не вернут.

**Мини-приложение**
- Всё введённое в заявлении и плата из квитанции сохраняются сами.
- Файлы скачиваются без ухода со страницы (устаревшая ссылка — сообщение, а не страница с ошибкой).
- Главная: активные дела сверху, закрытые — в архиве; «вернули меньше положенного» и «заявление устарело» видны в списке; итог не вылезает за край на 320 px.
- Тексты для мусора, холода и еле тёплой воды; вопрос про лифт — в карточке дома; «назад» из нового дела ведёт на главную.
- Доступность: рамки полей контрастнее, кнопки-ссылки и флажки крупнее, оранжевый статус темнее; газ — 🔥, «нет отопления» — ❄️.

## 1.0.3 — 24.09.2026

Исправления по отчёту строгого тестировщика (строгость 10/10, оценка 5/10).

**Документы больше не противоречат друг другу**
- Время отключения в акте меняется вместе с временем первого жителя; «дата составления» акта фиксирована; подписанный акт блокирует смену времени начала, пока не снята отметка.
- ФИО и квартиру в акте можно исправить до подписи; ФИО из заявления переносится в неподписанный акт, а при расхождении с подписанным — предупреждение.
- Квартира и лицевой счёт хранятся у адреса, а не у человека: чужая квартира больше не попадает в заявление по другому дому.
- Время звонка не выдумывается: для звонка спрашиваем именно время звонка (с него по закону считается нарушение), для номера соседа время не пишем.
- «Не сделали» и документы эскалации — только когда пришла квитанция за следующий месяц; дата подачи и входящий номер попадают в требование и жалобы; формулировка без «обратился(ась)».
- «Заявитель: ФИО» вместо несклонённого «от …», «г. Город, улица» в документах, имена файлов по делу и дате, дата заявления — дата первой выдачи.

**Деньги**
- Отключения одной услуги в одном месяце складываются: лимит на месяц общий, а положенное по прошлым отключениям вычитается, чтобы не посчитать дважды. Плата за месяц подставляется из другого дела.
- Итог «Вернули»: сумму можно вписать и исправить, отметку — снять; сумма сильно больше расчёта — переспрашиваем.
- Неполная сумма (плата вписана не за все месяцы) помечена; меньше часа «холодной» горячей воды — не повод для заявления.

**Мини-приложение**
- Порядок экрана дела: сначала «починили» и деньги (плата из квитанции рядом с суммой), потом заявление, «Что дальше», акт, факты.
- «Что дальше» — куда именно подавать (получатель из шапки заявления), дата подачи, результат по квитанции.
- Город: сокращения («Питер», «Мск») и опечатки («Масква» → «Возможно, Москва?»); квартира из строки адреса отделяется; улица с заглавной буквы; квартира — при добавлении адреса.
- Карточка дома сохраняется сама; замеры можно удалять; «уже норма» — подсказка; «еле тёплая» поверх «нет горячей воды» не заводится.
- Тексты под каждую проблему и способ сообщения, описания плиток, вопрос про лифт вместо «ввода электричества», подсказка про межсезонье, без ссылок на законы в подсказках, нейтральный род.
- Крупнее подсказки, дольше сообщения (закрываются нажатием), выбранная плитка с галочкой, числа не отрываются от единиц, удаление всех данных — с подтверждением на экране.
- Отключение до года назад (было — три месяца).

## 1.0.2 — 24.09.2026

Исправления по отчёту независимого тестировщика (оценка 7/10).

**Ошибки**
- Повторное сообщение о той же проблеме больше не теряет новый номер заявки: он сохраняется, житель видит «это у вас уже записано».
- Телефон аварийной службы — только цифры (и в мини-приложении, и в чате): слово вместо номера ломало кнопку «позвонить» у всех соседей.
- Подъезд — только номер вида «2» или «2А»: мусор больше не попадает в акт.

**Удобство**
- Ошибки показываются под полем с красной рамкой, все сразу, а не по одной во всплывающем сообщении.
- Исправить время начала и окончания, «Ещё не починили — вернуть», удалить дело, снять отметку «акт подписан».
- Новые замеры температуры в деле; для холода и еле тёплой воды — свои слова («Стало тепло?», «Слежу за температурой», «С какого времени холодно»).
- После заявления — «Что дальше»: адрес и почта УК из карточки дома, отметка «перерасчёт сделали / не сделали»; если не сделали — требование о штрафе 50%, жалоба в ГЖИ и заявление в общество потребителей прямо в приложении.
- «Запомнить ФИО, квартиру и лицевой счёт» для следующих заявлений; адрес УК из карточки дома попадает в заявление.
- Подсказки: кому подавать заявление, что значат «вводы электричества» и «плановое отключение», что делать без председателя совета дома; «доплаты» → «снижение платы», без «градусо-часов».
- «В сети пока только вы» вместо «соседей в сети: 1»; выбранный адрес отмечен галочкой; нет «добавить новый дом», если такой дом уже в списке; «Адрес уже есть в вашем списке».
- Полученный перерасчёт показывается как итог («Вернули 115,20 ₽»), без формы для правки.

## 1.0.0 — 23.09.2026

Первая полная версия для онлайн-этапа хакатона MAX (трек «Умный город»).

**Бот**
- Фиксация отключения или плохого качества: услуга, адрес, звонок в аварийную службу (номер заявки), время начала; замеры температуры.
- Напоминания «починили?» и расчёт снижения платы по Приложению № 1 к ПП РФ № 354 (оценка снизу, формула и пункт в тексте).
- Заявление на перерасчёт в PDF по образцу Минстроя (прил. 3.4, приказ № 1411/пр): «Руководителю …», контакты заявителя, приложения, отметка о принятии.
- Адрес: сначала город (справочник с часовыми поясами), затем дом из списка — соседи попадают в один дом. Несколько адресов у одного жителя, подъезд у каждого адреса.
- Сеть дома: бот сам пишет соседям «у вас тоже?», присоединение одной кнопкой, приглашение по ссылке.
- Карточка дома с данными из квитанции: УК, ИНН, телефон аварийной службы, поставщики — подставляются в подсказки и заявление.
- Акт без исполнителя (п. 110(1)): PDF для подписи сразу, с пустыми строками для соседей и председателя; соседей из бота бот вписывает сам. Способ и средство измерения в акте.
- Короткое объяснение «акт — доказательство, заявление — требование денег»; предупреждение, если в заявлении нет ни номера заявки, ни акта.
- Фото к делу, проверка квитанции через месяц, эскалация: требование о штрафе 50% (ч. 6 ст. 157 ЖК), жалоба в ГЖИ с числом домов исполнителя, заявление в общество защиты прав потребителей.

**Мини-приложение**
- Главная, «Мои адреса» с поиском дома по городу, карточка дома, «Сообщить о проблеме», дело с расчётом и формой заявления, QR квитанции, скачивание PDF, пересылка карточки в домовой чат.

**Запуск**
- `npm run demo` — демо без токена, `npm run setup` — создание `.env`, Docker Compose одной командой.
- Сертификат Russian Trusted Root CA для API MAX в комплекте.
- 49 автотестов: движок расчёта, сквозные сценарии бота, REST, миграция БД.
