# Изменения

## 1.0.0 — 23.09.2026

Первая полная версия для онлайн-этапа хакатона MAX (трек «Умный город»).

**Бот**
- Фиксация отключения или плохого качества: услуга, адрес, звонок в аварийную службу (номер заявки), время начала; замеры температуры.
- Напоминания «починили?» и расчёт снижения платы по Приложению № 1 к ПП РФ № 354 (оценка снизу, формула и пункт в тексте).
- Заявление на перерасчёт в PDF по образцу Минстроя (прил. 3.4, приказ № 1411/пр): «Руководителю …», контакты заявителя, приложения, отметка о принятии.
- Адрес: сначала город (справочник с часовыми поясами), затем дом из списка — соседи попадают в один дом. Несколько адресов у одного жителя, подъезд у каждого адреса.
- Сеть дома: бот сам пишет соседям «у вас тоже?», присоединение одной кнопкой, приглашение по ссылке.
- Карточка дома с данными из квитанции: УК, ИНН, телефон аварийной службы, поставщики — подставляются в подсказки и заявление.
- Акт без исполнителя (п. 110(1)): PDF для подписи сразу, с пустыми строками для соседей и председателя; соседей из бота бот вписывает сам. Способ и средство измерения в акте.
- Короткое объяснение «акт — доказательство, заявление — требование денег»; предупреждение, если в заявлении нет ни номера заявки, ни акта.
- Фото к делу, проверка квитанции через месяц, эскалация: требование о штрафе 50% (ч. 6 ст. 157 ЖК), жалоба в ГЖИ с числом домов исполнителя, заявление в общество защиты прав потребителей.

**Мини-приложение**
- Главная, «Мои адреса» с поиском дома по городу, карточка дома, «Сообщить о проблеме», дело с расчётом и формой заявления, QR квитанции, скачивание PDF, пересылка карточки в домовой чат.

**Запуск**
- `npm run demo` — демо без токена, `npm run setup` — создание `.env`, Docker Compose одной командой.
- Сертификат Russian Trusted Root CA для API MAX в комплекте.
- 49 автотестов: движок расчёта, сквозные сценарии бота, REST, миграция БД.
