# Изменения

## 1.0.2 — 24.09.2026

Исправления по отчёту независимого тестировщика (оценка 7/10).

**Ошибки**
- Повторное сообщение о той же проблеме больше не теряет новый номер заявки: он сохраняется, житель видит «это у вас уже записано».
- Телефон аварийной службы — только цифры (и в мини-приложении, и в чате): слово вместо номера ломало кнопку «позвонить» у всех соседей.
- Подъезд — только номер вида «2» или «2А»: мусор больше не попадает в акт.

**Удобство**
- Ошибки показываются под полем с красной рамкой, все сразу, а не по одной во всплывающем сообщении.
- Исправить время начала и окончания, «Ещё не починили — вернуть», удалить дело, снять отметку «акт подписан».
- Новые замеры температуры в деле; для холода и еле тёплой воды — свои слова («Стало тепло?», «Слежу за температурой», «С какого времени холодно»).
- После заявления — «Что дальше»: адрес и почта УК из карточки дома, отметка «перерасчёт сделали / не сделали»; если не сделали — требование о штрафе 50%, жалоба в ГЖИ и заявление в общество потребителей прямо в приложении.
- «Запомнить ФИО, квартиру и лицевой счёт» для следующих заявлений; адрес УК из карточки дома попадает в заявление.
- Подсказки: кому подавать заявление, что значат «вводы электричества» и «плановое отключение», что делать без председателя совета дома; «доплаты» → «снижение платы», без «градусо-часов».
- «В сети пока только вы» вместо «соседей в сети: 1»; выбранный адрес отмечен галочкой; нет «добавить новый дом», если такой дом уже в списке; «Адрес уже есть в вашем списке».
- Полученный перерасчёт показывается как итог («Вернули 115,20 ₽»), без формы для правки.

## 1.0.1 — 24.09.2026

Проверка мини-приложения глазами нового пользователя.

- Город выбирается кнопками (свои и крупные города) или вводом со своими подсказками — `datalist` на телефонах не работал; новому жителю «Москва» больше не подставляется молча.
- После обновления телефон больше не показывает старую версию: к `app.js` и `app.css` дописывается хеш содержимого.
- «Сообщить о проблеме»: если адресов несколько — подсказка «выберите адрес», продолжение формы само прокручивается в видимую часть; из карточки дома адрес подставляется сразу.
- «Позвать соседей» без MAX больше не падает с ошибкой сервера: ссылка «у меня тоже» уходит в системное «Поделиться» или копируется.
- Скачивание PDF не блокируется браузером и блокировщиками рекламы (без всплывающих окон); после заявления — блок «Что дальше».
- Акт с соседями прямо в мини-приложении: PDF для подписи и отметка «подписан».
- Сумма в рублях — сразу при вводе начисления; УК подставляется из карточки дома, ФИО и квартира — из акта.
- Главная: «Как это работает» в три шага; карточка дома — лишние поля свёрнуты, кнопка «Сообщить о проблеме в этом доме».

## 1.0.0 — 23.09.2026

Первая полная версия для онлайн-этапа хакатона MAX (трек «Умный город»).

**Бот**
- Фиксация отключения или плохого качества: услуга, адрес, звонок в аварийную службу (номер заявки), время начала; замеры температуры.
- Напоминания «починили?» и расчёт снижения платы по Приложению № 1 к ПП РФ № 354 (оценка снизу, формула и пункт в тексте).
- Заявление на перерасчёт в PDF по образцу Минстроя (прил. 3.4, приказ № 1411/пр): «Руководителю …», контакты заявителя, приложения, отметка о принятии.
- Адрес: сначала город (справочник с часовыми поясами), затем дом из списка — соседи попадают в один дом. Несколько адресов у одного жителя, подъезд у каждого адреса.
- Сеть дома: бот сам пишет соседям «у вас тоже?», присоединение одной кнопкой, приглашение по ссылке.
- Карточка дома с данными из квитанции: УК, ИНН, телефон аварийной службы, поставщики — подставляются в подсказки и заявление.
- Акт без исполнителя (п. 110(1)): PDF для подписи сразу, с пустыми строками для соседей и председателя; соседей из бота бот вписывает сам. Способ и средство измерения в акте.
- Короткое объяснение «акт — доказательство, заявление — требование денег»; предупреждение, если в заявлении нет ни номера заявки, ни акта.
- Фото к делу, проверка квитанции через месяц, эскалация: требование о штрафе 50% (ч. 6 ст. 157 ЖК), жалоба в ГЖИ с числом домов исполнителя, заявление в общество защиты прав потребителей.

**Мини-приложение**
- Главная, «Мои адреса» с поиском дома по городу, карточка дома, «Сообщить о проблеме», дело с расчётом и формой заявления, QR квитанции, скачивание PDF, пересылка карточки в домовой чат.

**Запуск**
- `npm run demo` — демо без токена, `npm run setup` — создание `.env`, Docker Compose одной командой.
- Сертификат Russian Trusted Root CA для API MAX в комплекте.
- 49 автотестов: движок расчёта, сквозные сценарии бота, REST, миграция БД.
