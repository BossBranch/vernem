# «Вернём» — бот в MAX, который помогает вернуть деньги за плохие коммунальные услуги

**Версия 1.3.0**, [список изменений](CHANGELOG.md)

Если в доме три дня нет горячей воды или в квартире +15 °C, плату за месяц должны снизить. Это прописано в правилах предоставления коммунальных услуг (ПП РФ № 354). Но почти никто деньги не возвращает: непонятно, как доказать нарушение, сколько положено и что писать в управляющую компанию.

«Вернём» ведёт жителя по всему пути, от «что-то сломалось» до перерасчёта в квитанции:

1. **Помогает зафиксировать проблему.** Подсказывает позвонить в аварийную службу и записать номер заявки. Не дозвонились — помогает составить акт с соседями.
2. **Зовёт соседей.** Бот сам пишет жителям того же дома «У вас тоже?». Сосед присоединяется одной кнопкой.
3. **Считает деньги** по нормам и показывает, как посчитано.
4. **Готовит заявление на перерасчёт в PDF.** Остаётся распечатать и отнести.
5. **Через месяц спрашивает про квитанцию.** Если деньги не вернули, готовит требование о штрафе 50% и жалобу в жилищную инспекцию.

Бот и мини-приложение работают как один сервис. В чат приходит то, что должно приходить само: вопросы соседям и напоминания. В мини-приложении удобно заполнять формы и смотреть свои дела.

Трек хакатона MAX «Умный город», направление «Аварии, заявки и коммунальные услуги в доме».

## Быстрый старт

Нужны **Node.js 22.19 или новее** (подойдёт и 24 LTS) и Git. Docker нужен только для запуска в контейнере.

**1. Скачать и проверить**

```bash
git clone https://github.com/BossBranch/vernem.git
cd vernem
npm ci
npm test
```

В конце должно быть `pass 77` и `fail 0`.

**2. Посмотреть без токена.** Мини-приложение с демо-делами откроется в обычном браузере:

```bash
npm run demo
```

Откройте http://localhost:3000/app/?demo=1. Там три демо-дела:
- **Демо 1:** дозвонились в аварийную, есть номер заявки, заявление готово;
- **Демо 2:** не дозвонились, собран акт с соседями. Отметьте, что акт подписан, потом «Воду дали», и акт попадёт в заявление;
- **Демо 3** (в архиве): вернули меньше, чем положено. Здесь видно, как потребовать остальное.

Демо хранится в отдельной базе `data/demo.db`. Чтобы начать заново, удалите её. Остановить сервер можно через Ctrl+C.

**3. Запустить бота** (нужен токен бота):

```bash
npm run setup
```

Команда создаст файл `.env`. Впишите в него строку `MAX_BOT_TOKEN=…` и запустите:

```bash
npm run dev
```

Напишите боту в MAX `/start`. Или запустите всё в Docker: `docker compose up -d --build`.

**Полезно знать**
- Токен хранится только в `.env`, этот файл в репозиторий не попадает.
- С одним токеном должен работать один бот. Если бот уже запущен на сервере, локальная копия с тем же токеном будет ему мешать.
- API MAX использует сертификат Минцифры, которому Node.js по умолчанию не доверяет. Сертификат уже лежит в проекте (`assets/certs/`), бот подключает его сам. Отключать проверку сертификатов не нужно.
- `ALLOW_DEMO_AUTH=true` открывает мини-приложение без MAX. Это только для своего компьютера, на сервере должно быть `false`.
- Папка `data/` с базой в репозиторий не попадает.

## Как работает бот

Житель нажимает «🚨 Что-то сломалось» и отвечает на вопросы.

1. **Что случилось.** Нет горячей или холодной воды, света, газа, отопления, холодно в квартире, вода еле тёплая, засор канализации, не вывозят мусор.
2. **Где.** Сначала город, потом дом из списка. Список общий для всех жителей, поэтому соседи попадают в один дом, даже если пишут адрес по-разному. Адресов у жителя может быть несколько.
3. **Фиксация.** Если УК дома подключена к боту, заявку можно отправить ей одной кнопкой: сотрудник УК принимает её в MAX, и номер с временем регистрации сразу приходят в дело. Иначе бот просит позвонить в аварийную службу и записать номер заявки. Если дозвониться не удалось, можно написать через «Госуслуги Дом» или составить акт с соседями.
4. **Соседи.** Бот пишет жителям дома «У вас тоже?». Ночью не беспокоит, ждёт до 8 утра.
5. **Акт.** Если номера заявки нет, бот сразу присылает акт в PDF. Его подписывают на бумаге, а соседей, которые отметились в боте, бот вписывает сам.
6. **Пока не починили**, бот раз в 3 часа спрашивает, дали ли воду. Ночью молчит. Можно добавлять замеры температуры и фото.
7. **Починили.** Житель отмечает время, бот считает, на сколько должны снизить плату. Для суммы в рублях нужна строка из квитанции.
8. **Заявление.** Бот спрашивает, кому подавать (УК, поставщик или оператор по вывозу мусора), ФИО, квартиру и лицевой счёт, и присылает PDF. Заявление сделано по образцу Минстроя, внизу есть место для отметки о приёме. Если почта УК есть в карточке дома, бот может сам отправить заявление на неё: дата отправки становится датой подачи. ФИО и квартиру бот хранит, только если житель разрешил.
9. **Через 30 дней** бот спрашивает, пришёл ли перерасчёт. Если нет или вернули меньше, готовит требование о штрафе 50%, жалобу в жилищную инспекцию и заявление в общество защиты прав потребителей. В жалобу бот добавляет, в скольких ещё домах у той же УК были подтверждённые нарушения за 90 дней.

## УК в боте

Жители не должны сами бегать между ботом и УК. Поэтому УК может подключиться к боту, и тогда заявки идут ей напрямую.

1. **Приглашение.** В карточке дома житель нажимает «Пригласить УК в бот» и пересылает сообщение со ссылкой в УК: в её чат в MAX, диспетчеру или на почту.
2. **Подключение.** Сотрудник УК открывает ссылку и пишет, как его указывать в заявках, например «Иванова А. П., диспетчер ООО «УК Пример»». Жители дома получают сообщение, что УК теперь принимает заявки в боте. Житель того же дома не может подключиться как УК: иначе он подтверждал бы заявку сам себе.
3. **Заявка.** Житель нажимает «Отправить заявку в УК». Сотруднику приходит карточка: адрес, подъезд, что случилось, сколько жителей сообщили. Кнопки «Принять», «Принять со своим номером» и «Не наш дом».
4. **Ответ.** Приняли — все жители этого отключения сразу получают номер и время регистрации, номер попадает в заявление. Дальше сотрудник отмечает «Выехали» и «Устранено», а жители подтверждают окончание одной кнопкой.
5. **УК молчит.** Если за 30 минут заявку никто не принял, бот это записывает и советует позвонить или собрать акт с соседями. В заявлении будет сказано, что сообщение отправлено, а номер не сообщили.

Для нас ответ УК — доказательство: номер и время регистрации, которые раньше житель записывал вручную. Это работает в MAX, где УК с 1 сентября 2026 года обязаны общаться с жителями.

## Мини-приложение

Открывается из бота кнопкой «📱 Открыть приложение». Сценарий тот же, но в формах.
- **Главная:** «Сообщить о проблеме», мои адреса с кнопкой звонка в аварийную, мои дела, сколько уже вернули и сколько ещё можно вернуть.
- **Сообщить о проблеме:** адрес, что случилось, номер заявки (или «номера нет») и время.
- **Дело:** четыре шага (Записали, Воду дали, Заявление, Квитанция) и блок «Сейчас» с тем, что сделать дальше. Крупно показано, сколько положено вернуть, а формула спрятана под «Как посчитано».
- **Документы:** акт с соседями и заявление в PDF. Получателя и лицевой счёт можно считать с QR-кода квитанции.
- **Карточка дома:** подъезд, уведомления, ссылка для соседей, данные УК из квитанции, кто из УК принимает заявки в боте и приглашение для УК. Эти данные общие для всего дома и сами попадают в заявления.
- **Заявка в УК и почта:** в форме «Сообщить о проблеме» можно сразу отправить заявку в УК, в деле видно, приняли ли её. Готовое заявление бот отправит на почту УК одной кнопкой.
- **Домовой чат:** карточку «У вас тоже?» можно переслать в чат дома.

Крупный текст и кнопки, светлая и тёмная тема.

## Как устроено

```
MAX (мобильный и веб-клиент)
 ├─ диалог с ботом ───────────────┐
 ├─ домовой чат (/dom, карточки) ─┼──► app: Node.js 22 + TypeScript (один контейнер)
 └─ мини-приложение ──────────────┘      ├─ src/bot/core.ts       сценарий (не зависит от SDK MAX)
                                         ├─ src/bot/house.ts      дома и уведомления соседям
                                         ├─ src/bot/acts.ts       акт с соседями
                                         ├─ src/bot/photos.ts     фото к делу
                                         ├─ src/bot/escalate.ts   штраф 50%, жалоба, общество потребителей
                                         ├─ src/bot/dispatch.ts   УК в боте: заявки, «Принять», «Устранено»
                                         ├─ src/bot/mail.ts       заявление на почту УК (src/mail/smtp.ts)
                                         ├─ src/bot/max-adapter.ts  связь с SDK MAX
                                         ├─ src/calc/             расчёт (без ИИ)
                                         ├─ norms/norms.yaml      нормы с источником и датой проверки
                                         ├─ src/docs/             заявление, акт, требование, жалоба в PDF
                                         ├─ src/web/              REST мини-приложения, файлы PDF
                                         ├─ src/scheduler.ts      напоминания
                                         ├─ src/receipt/qr.ts     QR-код квитанции
                                         ├─ public/app/           мини-приложение (HTML/CSS/JS)
                                         └─ SQLite (node:sqlite)  data/vernem.db
```

Это один сервис с базой SQLite, которая встроена в Node.js. Логика бота не зависит от SDK MAX, поэтому один и тот же код работает в MAX, в терминальном симуляторе и в тестах. Расчёт сделан обычными функциями по таблице норм и покрыт тестами. ИИ в продукте не используется.

## Запуск в Docker

```bash
cp .env.example .env        # впишите MAX_BOT_TOKEN
docker compose up -d --build
```

- Без публичного адреса бот работает через long polling, HTTPS не нужен.
- Сервер слушает порт 3000: `/health` и мини-приложение `/app/`.
- Без токена работает только веб-часть, а `/health` показывает `bot: disabled`.
- Нужен Docker Compose 2.24 или новее.

**С доменом и HTTPS.** В `.env` задайте `PUBLIC_URL=https://ваш-домен`, `DOMAIN=ваш-домен`, `MINIAPP_ENABLED=true` и запустите:

```bash
docker compose --profile https up -d --build
```

Caddy сам получит сертификат. Бот переключится на webhook `https://ваш-домен/webhook/max`, мини-приложение будет доступно по адресу `https://ваш-домен/app/`. Подробнее — в [DEPLOY.md](DEPLOY.md).

**Остановка и перезапуск:**

```bash
docker compose down            # остановить (данные остаются в томе vernem-data)
docker compose up -d           # запустить снова
docker compose logs -f app     # логи
docker compose down -v         # остановить и удалить все данные
```

Напоминания хранятся в базе, поэтому после перезапуска они не теряются.

## Переменные окружения

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `MAX_BOT_TOKEN` | — | Токен бота. Только в `.env` |
| `BOT_USERNAME` | из API | Ник бота для ссылок соседям |
| `PUBLIC_URL` | — | Публичный HTTPS-адрес. Если задан, бот работает через webhook |
| `BOT_MODE` | `polling` / `webhook` | Выбрать режим вручную |
| `WEBHOOK_SECRET` | из токена | Секрет для webhook |
| `DOMAIN` | — | Домен для Caddy (профиль `https`) |
| `MINIAPP_ENABLED` | `false` | Показывать кнопку мини-приложения (нужен `PUBLIC_URL`) |
| `ALLOW_DEMO_AUTH` | `false` | Вход в мини-приложение без MAX. Только для локальной проверки |
| `DEMO_MODE` | `true` | Кнопка «🧪 Демо» в боте |
| `FAST_REMINDERS` | `false` | Напоминания через 2–3 минуты вместо часов и дней |
| `RESTORE_CHECK_HOURS` | `3` | Как часто спрашивать «починили?» |
| `RECEIPT_CHECK_DAYS` | `30` | Через сколько дней спросить про перерасчёт |
| `DEFAULT_TZ` | `Europe/Moscow` | Часовой пояс по умолчанию |
| `HOST_PORT` | `3000` | Порт на хосте |
| `ADMIN_IDS` | — | ID администраторов в MAX, им доступна команда `/stats` |
| `PARTNER_ORG_NAME` | — | Общество защиты прав потребителей, которому житель может передать дело. Пусто — бот говорит, что партнёра нет |
| `PARTNER_ORG_URL` | — | Сайт партнёра (только `https://`) |
| `SMTP_HOST` | — | Почтовый сервер для отправки заявлений в УК. Пусто — отправка на почту выключена |
| `SMTP_PORT` | `465` | Порт: 465 (шифрование сразу) или 587 (STARTTLS) |
| `SMTP_USER`, `SMTP_PASS` | — | Ящик и пароль приложения для отправки |
| `SMTP_FROM`, `SMTP_FROM_NAME` | `SMTP_USER`, `Вернём` | Адрес и имя отправителя |

**Порты:** приложение слушает 3000 внутри контейнера, Caddy — 80 и 443.

**Зависимости** зафиксированы в `package-lock.json`: `@maxhub/max-bot-api` 0.3.1 (официальный SDK MAX), `express` 5.2.1, `pdfkit` 0.20.2, `yaml` 2.9.1. Все лицензии свободные.

## Внешние сервисы

- **MAX Bot API** через официальный SDK. Для проверки нужен токен бота.
- **MAX Bridge** в мини-приложении: данные запуска (сервер проверяет их подпись), сканер QR-кодов, скачивание файлов, пересылка в чат.
- **Почта (SMTP)** — только для отправки заявления на почту УК, если её настроили. Своя реализация на встроенных модулях Node.js, без шифрования пароль не отправляется.
- **С ГИС ЖКХ и «Госуслуги Дом» интеграций нет.** Доступ к ним дают только самим организациям. Вместо этого УК подключается к боту в MAX, а заявление бот может отправить на её почту.

## Собственный API

У мини-приложения есть свой REST. Он описан в [`openapi.yaml`](openapi.yaml) (OpenAPI 3.0), тестовые доступы лежат в [`DATA-API.yaml`](DATA-API.yaml). Отдельный тест следит, чтобы описание совпадало с кодом сервера.

- **Адрес:** https://vernem.xyz (локально http://localhost:3000).
- **Вход:** заголовок `X-Max-Init-Data`, это данные запуска мини-приложения, подписанные токеном бота. Чтобы проверить API без MAX, выполните `npm run init-data`: команда подпишет такую строку токеном из `.env`.
- **Локально без токена:** `npm run demo` и заголовок `X-Demo-User: 900000001`.

```bash
curl -s https://vernem.xyz/health
curl -s -o /dev/null -w "%{http_code}\n" https://vernem.xyz/api/me   # 401 без подписи
curl -s -H "X-Max-Init-Data: $(npm run -s init-data)" https://vernem.xyz/api/me
```

## Данные

- **Нормы** лежат в `norms/norms.yaml`. У каждой указаны пункт закона, ссылка на источник и дата проверки.
- **Что храним:** адрес и подъезд, дела (время, номер заявки, замеры, плата), статус заявления. ФИО, квартиру и лицевой счёт храним, только если житель нажал «Запомнить».
- **Акты:** ФИО и квартиры подписантов хранятся в акте, без них акт не составить. Житель видит это до подтверждения.
- **Фото:** храним только ссылку MAX на фото, сами файлы не скачиваем.
- **Удалить всё** можно командой `/delete_me` или кнопкой в мини-приложении.
- **Уведомления соседям** получают только жители того же дома. Их можно отключить.
- Данные никуда не передаются. Для работы с реальными жителями сервер должен стоять в России (152-ФЗ).
- **Статистика:** команда `/stats` показывает, сколько людей дошло до каждого шага.

**Демо-данные помечены.** Кнопка «🧪 Демо» создаёт дело в доме «ДЕМО: ул. Примерная, 5», в документах стоит пометка «ДЕМОНСТРАЦИОННЫЕ ДАННЫЕ». Команда `npm run seed:demo` заполняет базу демо-делами для жителя 900000001. В тестах только выдуманные данные.

## Как проверить

**В MAX:**
1. **Демо 1, есть номер заявки.** «🧪 Демо» → «📞 1. Есть номер заявки». Бот начнёт следить за отключением с заявкой ДЕМО-4512.
2. «✅ Воду дали» → «Только что». Бот запишет время.
3. Введите **1200**. Бот покажет расчёт: 64 часа сверх нормы, снижение 9,6%, около **115,20 ₽**.
4. «УК / ТСЖ», ФИО и квартира, «Пропустить», «Не сохранять». Придёт заявление в PDF и подсказка, как его подать.
5. **Демо 2, номера нет.** «🧪 Демо» → «📵 2. Не дозвонились» → «📄 Акт с соседями» → ФИО и квартира. Придёт акт в PDF, два демо-соседа уже вписаны. Дальше «✅ Акт подписан» → «Да, и председатель» → «К делу» → «Воду дали» → «Только что» → **600**. В заявлении будет сказано, что дозвониться не удалось, а акт попадёт в приложения.
6. **Своё дело:** «Что-то сломалось» → «Нет горячей воды» → адрес → «Внезапно» → «Позвонил» → номер → время.
7. **Соседи:** «👥 Позвать соседей», бот пришлёт ссылку. Второй аккаунт открывает её и нажимает «Да, у меня тоже», а первому приходит «Присоединился сосед».
8. **Два аккаунта в одном доме:** второй аккаунт добавляет тот же дом в «🏠 Мои адреса». Когда первый сообщит об отключении, второму придёт «У вас тоже?».
9. **Домовой чат:** добавьте бота в групповой чат, напишите там `/dom`, потом в личке «Позвать соседей» → «Опубликовать в чате дома».
10. **Напоминания без ожидания:** с `FAST_REMINDERS=true` вопрос «починили?» придёт через 2 минуты, а «перерасчёт пришёл?» через 3 минуты после заявления. Ответьте «❌ Нет», и бот предложит требование о штрафе, жалобу и заявление в общество потребителей.
11. **Данные дома:** «🏠 Мои адреса» → дом → «✏️ Данные дома». Впишите УК и телефон аварийной: телефон появится в подсказке «Позвоните…», а УК сама подставится в заявление.
12. **Фото:** пришлите фото, пока дело открыто. Бот сохранит его, а в заявлении появится строка «Фотографии (1 шт.)».
13. **Ошибки:** напишите «25:99» вместо времени или «дом» вместо адреса. Бот объяснит, что не так, и даст кнопку «В начало».
14. **УК в боте (два аккаунта):** житель → «🏠 Мои адреса» → дом → «🏢 Пригласить УК в бот», второй аккаунт (не житель этого дома) открывает ссылку и пишет имя и организацию. Житель: «Что-то сломалось» → «Нет горячей воды» → «Внезапно» → «📨 Отправить заявку в УК». Второй аккаунт: «✅ Принять» — у жителя появляется номер заявки, потом «🚗 Выехали» и «✅ Устранено» — житель нажимает «Да» и сразу переходит к расчёту.
15. **Заявление на почту:** нужны настройки `SMTP_*` и почта УК в карточке дома. После заявления — «📧 Отправить в УК на почту».

## Ограничения

- **Расчёт примерный и нарочно занижен.** Неполные часы не считаются, некоторые редкие случаи не учтены. Точную сумму определяет УК.
- **Нормы сверены с текстом закона**, но спорные места (горячая вода ниже +40 °C, оплата отопления) стоит показать юристу.
- **Список домов ведёт сам сервис:** дом появляется, когда его добавит первый житель. Официальную базу адресов ФИАС не подключили: доступ к её API выдают по заявке, и ждать долго.
- **Данные УК вносят жители** по квитанции. Официальный источник — ГИС ЖКХ, но стороннему сервису доступа к нему нет.
- **УК подключается по ссылке от жителей.** Бот не проверяет, что сотрудник действительно работает в УК: в заявке указано, кто её принял, а житель того же дома подключиться как УК не может. Проверку через реестр УК можно добавить позже.
- **Жалобу в жилинспекцию житель подаёт сам:** интеграции с ГЖИ нет. Общество защиты прав потребителей подключается через `PARTNER_ORG_NAME`. Пока оно не задано, бот так и говорит.
- **Лифт, уборка и другое содержание дома** пока не поддерживаются.
- **Что проверено.** Бот и мини-приложение работают на сервере https://vernem.xyz, каждый push проверяется в GitHub Actions: тесты и сборка Docker-образа (около 20 секунд). В живом MAX ещё не проверяли приём фото, ссылки-приглашения у тех, кто уже запускал бота, и `/dom` в групповом чате без прав администратора.
- **Бот не юрист.** Итог перерасчёта решает исполнитель.
